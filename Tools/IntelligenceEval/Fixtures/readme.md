# tidy

## Install

```sh
brew install tidy
```

## Options

| Flag | Meaning |
| --- | --- |
| `-r` | Reverse the sort order |
| `-u` | Keep only unique lines |
| `-i` | Ignore case when comparing |

## Usage

Run `tidy notes.txt` to sort the lines of a file in place. Pass `-` to read from standard input instead.
